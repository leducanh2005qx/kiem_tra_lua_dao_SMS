# Dataset attribution

Source: Vietnamese Quality-Assured SMS Scam Dataset, Tran Nguyen Thai Tuan et al.
https://huggingface.co/datasets/trannguyenthaituan/vietnamese_sms_dataset
https://github.com/trannguyenthaituan251209/vietnamese_sms_dataset

Publisher states CC BY 4.0. Cite creators and link to source when you use the dataset. This project ZIP does **not** include the dataset because network downloading was not possible in the authoring environment; run `python download_data.py` on a network-enabled machine.

Source labels: 0 = legitimate; 1 = spam / scam. The labels do not distinguish spam from scam.
